# Interface de Fabrique : composants libres livrés

L'interface est construite avec des composants libres, tous utilisables dans un produit commercial. Les fichiers construits (fenetre\web)
en contiennent le code ; le texte complet de chaque licence est dans le paquet d'origine (npm).

| Floating UI (@floating-ui/*) | 1.8 | MIT |
| Lucide (icônes, lucide-react) | 1.79.0 | ISC |
| Inter (police, @fontsource-variable/inter), par Rasmus Andersson | 5.3.0 | SIL Open Font License 1.1 |

| clsx, tailwind-merge | 2.1.1, 3.7.1 | MIT |

| tslib | 2.9.1 | 0BSD |
